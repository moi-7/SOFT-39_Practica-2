# 2. Perfil de usuario

## 2.1 Perfil seleccionado

**Discapacidad:** Motora.

Se considera un usuario que presenta limitaciones en el
control de movimientos precisos o en la manipulación
de dispositivos de entrada convencionales.

## 2.2 Necesidades de accesibilidad

El usuario necesita:

- Navegar por todos los elementos interactivos mediante teclado.
- Identificar visualmente qué elemento tiene el foco.
- Seleccionar opciones sin utilizar el ratón.
- Recibir una respuesta visual clara después de una selección.
- Mantener un orden de navegación lógico y predecible.

## 2.3 Habilidades y limitaciones

| Aspecto | Descripción |
|:---|:---|
| Habilidades | Puede utilizar determinadas teclas para navegar e interactuar. |
| Limitaciones | Puede presentar dificultades para controlar un ratón o realizar movimientos precisos. |
| Necesidad principal | Acceso completo a los controles mediante teclado. |

## 2.4 Tecnologías asistivas

| Tecnología | Función |
|:---|:---|
| Teclado físico | Permite navegar y activar controles sin utilizar el ratón. |
| Teclado adaptado | Puede facilitar la interacción a personas con movilidad reducida. |
| Teclas de accesibilidad del sistema operativo | Facilitan la introducción de determinadas combinaciones de teclas. |

## 2.5 Impacto de las barreras

La ausencia de mecanismos adecuados de navegación
mediante teclado puede impedir que el usuario complete
acciones esenciales, como seleccionar un perfil o activar
una opción dentro de un formulario o tabla de datos.

```{note} Consideración sobre el perfil:
la discapacidad motora comprende distintas condiciones y
niveles de movilidad. Las necesidades descritas representan
un escenario de evaluación y no una característica universal
de todas las personas con esta discapacidad.
```
