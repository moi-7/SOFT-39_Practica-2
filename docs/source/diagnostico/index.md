# 3. Diagnóstico de accesibilidad

## 3.1 Metodología

El diagnóstico se realizó mediante la inspección de la
interfaz original de la Oficina Virtual de la CCSS.

Se identificaron problemas relacionados con la navegación
mediante teclado y la interacción con componentes de selección.

Para documentar las barreras se utilizaron los siguientes
elementos:

- Inspección visual.
- Pruebas manuales de teclado.
- Principios de accesibilidad POUR.
- Criterios WCAG 2.1.
- Evaluación mediante WAVE.
- Herramientas para desarrolladores disponible en navegadores.

## 3.2 Barreras identificadas

| ID   | Componente         | Problema                                                                                     | Principio POUR |
|:-----|:-------------------|:---------------------------------------------------------------------------------------------|:---------------|
| B-01 | Selección de perfil | Dificultad para navegar y seleccionar opciones mediante teclado.                            | Operable       |
| B-02 | Lista de facturas       | Interacción confusa y limitada a flechas de navegación al hacer uso del teclado.            | Operable       |
